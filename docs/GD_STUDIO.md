# GD音乐台接入说明

## v1.8.14 测试版升级记录

- 新增可选 GD 网易云播放解析，按返回码率分档；不改变默认音源或搜索、歌单、同步协议。
- 增加超时、取消、换源检查、短期内存缓存和限流；GD 地址不进入原有持久缓存。
- 遵守当前 GD 禁止下载的限制，其他允许下载的音源保持原有功能。
- 升级无需清除应用数据或修改同步服务器。安装本仓库对应测试包后，在设置中手动选择 GD。
- 本次为测试发布，自动化和构建通过不等于已完成实机或音质实听验收。

## 使用范围

GD音乐台(music.gdstudio.xyz) 是可选的在线播放解析服务。第一版只对接网易云歌曲 ID（LX 的 `wy` → GD 的 `netease`），不接管搜索、歌单、收藏、歌词、封面或私有同步服务。JOOX、Bilibili 等搜索和歌曲模型不在这一版范围内。

- 设置 → 基本设置 → 音源，手动选择 **GD音乐台（网易云·在线播放）**。
- 仍使用现有网易云搜索和歌单；其他平台的歌曲是否能播放，取决于现有换源逻辑能否找到对应的网易云版本。
- 在播放设置中选择 128k、320k 或无损。建议先用 320k 验证自己的网络和设备。
- 各设备需要安装支持本功能的客户端，并分别选择该音源；无需修改或升级同步服务。
- 不自动启用，也不在其他自定义音源失效后擅自切换到 GD。选择原有自定义音源即可恢复原有流程。

## 音质与稳定性

| LX 档位 | GD 请求参数 |
| --- | --- |
| 128k | 128 |
| 320k | 320 |
| 无损 | 740 |

服务可能返回低于所请求档位的音质。适配器使用接口返回的实际码率分档，不把请求值当作已获得音质；码率不足 320 的有损结果保守归入 128k。接口码率不是音频文件头验证，因此这一版不宣称 24-bit/Hi-Res，也没有新增逐首音频参数显示界面。

- 每次解析请求超时 12 秒；不自动密集重试。
- 临时地址仅在内存保存 2 分钟，最多 40 条；主动刷新会绕过内存缓存。
- 每个客户端本地限制 5 分钟内最多 40 次解析请求，低于官方文档的 50 次限制。但多设备共用网络可能共同触发服务端限流，本地限制不能保证免限流。
- 临时播放地址不读取或写入原有跨音源共享的持久缓存，避免换源后误用 GD 地址。
- 只接受 HTTPS 播放地址；取消请求或切换音源后丢弃未完成请求结果；错误信息不回显完整地址和令牌。

## 下载与使用限制

依据 [GD 官方接口说明](https://music-api.gdstudio.xyz/api.php)（本次核对日期：2026-10-11）：

- 仅限学习参考；禁止下载、传播或商用；使用须注明 GD音乐台(music.gdstudio.xyz)。
- 当前 GD 接入只用于在线播放，不新增下载或离线导出能力。
- 桌面版真实下载入口会在创建、解析和刷新任务时检查来源，GD 被禁止下载；其他音源下载和已下载文件的播放保持原有行为。
- 手机和车机没有因为接入 GD 新增下载入口。
- “返回播放地址”不等于“许可下载”。如果将来官方明确允许下载，需核对新的授权范围后再调整 GD 限制；允许下载的其他接口不受本限制影响。

客户端播放所需的缓冲不等于新增离线下载功能。第三方接口的访问会使服务提供方获得正常网络请求信息；私有同步服务不代理 GD 流量。音乐内容及其使用还应遵循权利人的授权和适用规则。

## 验证与回归

`node --test tests/gd-studio.test.cjs` 覆盖质量参数、实际码率降级、无效响应、HTTPS 校验、超时错误、取消、换源、缓存隔离、主动刷新、限流和下载边界。测试使用合成地址，不下载音乐文件。桌面版还验证实际下载任务入口。

发布前还应运行原有隐私、同步和车机 UI 检查。自动化检查、打包成功不等于已经完成 Android 真机、车机或音频设备实听验收。

## 实机验收清单

1. 原有音源、歌单、同步和本地文件播放正常。
2. 选中 GD 后，在网易云搜索结果中分别尝试 128k、320k 和无损歌曲。
3. 网络断开、超时、歌曲不可用时能退出等待或正常重试。
4. 切回原有音源，不使用 GD 的缓存地址；播放失败后主动刷新可获得新地址。
5. 桌面 GD 下载提示限制；切换到允许下载的音源后下载正常。
6. 手机发送歌曲到在线车机后，车机使用自己当前选中的音源解析；右侧系统窗口和实车按键不应受影响。
