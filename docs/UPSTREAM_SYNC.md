# 手机端上游同步与升级说明

## 本次版本

- Fork 版本：1.9.2，Android versionCode 87。
- 审查日期：2026-10-11。
- 上游稳定分支参考：lyswhut/lx-music-mobile v1.9.1，fb8480728d875fa5e0da25eebd3a26bb71723aae。
- 采用选择性移植，不代表完整合入上游全部提交；不覆盖发布流程、Fork 地址和原有定制。

## 引入内容

- QQ 音乐搜索请求与响应结构、歌单导入/翻页和推荐列表修复。
- 酷狗搜索结果、分享歌单完整分页，避免部分歌曲缺失。
- 咪咕封面/歌词修复、酷我歌单数据显示优化。
- 自动换源增加版本关键词校验，减少匹配到伴奏、现场版等错误版本。
- QQ QRC 改为纯 JavaScript 解密，酷我歌词流程及毫秒时间格式修复。
- 歌曲菜单新增单曲播放地址缓存清理，GD 内存缓存和普通音源持久缓存分别处理。
- 保留跨端设置隔离、音源同步、车机遥控、应用更新地址与 universal 测试签名构建。
- 保持 React Native 0.73.11、最低 Android API 21 和递增 versionCode。

## 保留的边界

- 自定义 JS 音源、歌单、收藏和跨端偏好同步保持原有扩展协议；服务端本轮无需更新。
- 主题、语言、布局、设备路径和认证信息不作为跨端通用设置覆盖。
- GD 必须手动选择；不增加自动兜底，不开放下载，不把临时播放地址写进共享持久缓存。
- 保留项目许可证和上游归属说明；新增文档不含账号口令、设备信息或私有服务地址。

## 升级方式

1. 从本 Fork Releases 下载本次测试版 universal APK。
2. 先导出歌单备份，再覆盖安装；不要为了更新主动清空数据。
3. 保留现有包名和测试签名。若设备提示签名不一致，应先核实旧包来源，不要直接卸载丢失本地数据。
4. 若上游接口仍被平台限流或调整，代码修复不代表所有网络环境都保证可用。

## 验证与待验证

- 自动回归：搜索响应、酷狗完整分页、版本匹配、QRC 固定文本往返、GD 缓存隔离、原有同步/隐私或车机界面检查。
- 本地生产模式 JavaScript bundle 构建；Android 原生 APK 由 GitHub Actions 构建。
- 云端构建成功只代表产物生成，不等于手机/实车/所有桌面系统验收。
- 真机需测试：QQ/酷狗歌单导入、搜索、歌词跟随、切换音源、重连和旧数据保留。
